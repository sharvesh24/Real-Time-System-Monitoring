## 🧠 What is This?

**Real-Time System Monitoring** is a Python-based web interface designed for **Machine Learning** and **High-Performance Computing (HPC)** environments. It captures system vitals such as CPU, GPU, memory, and storage usage — and visualizes them live in a web dashboard.

This tool provides real-time data, historical trends, and intelligent predictions through a lightweight ML model that detects anomalies and performance bottlenecks.

---

## 🌐 Key Capabilities

- 📊 Live system data visualizations (CPU, GPU, memory, logs)
- 🚀 Real-time ML training progress with timeline navigation
- 🧠 Smart anomaly detection and trend predictions
- 🧵 HBM (High Bandwidth Memory) usage tracking
- 🔄 Log review and performance iteration over time
- 🔍 Interactive cluster plots and summaries

## ⚙️ Getting Started

### 🔧 Prerequisites

- Python 3.8+
- Firebase Realtime Database
- Git

### 📦 Install Dependencies

> ☁️ Set up your Firebase database and add the URL to your environment or a config file.

### 🧪 Run the System Monitor

```bash
python send_data.py
```

### 🌐 Start the Dashboard

```bash
python app.py
```

> Navigate to `http://localhost:5000` in your browser to view your live dashboard.
